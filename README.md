# PushOS

PushOS is a toy command-line application written in C++ that simulates a simple operating system environment. It features a virtual file system, a command-line shell, basic file and directory operations, and a simulated user management system.

## Building and Running

Use `CMake` to build:

```sh
cmake -S . -B build
cmake --build build
```

Then run the generated `pushos` executable from the build directory.
